# Boda

Invitación digital de boda desarrollada con Next.js, React y TypeScript.

## Funcionalidades

- Invitaciones personalizadas por nombre, cantidad de pases y código.
- Cuenta regresiva, música, galería, ubicación y código de vestimenta.
- Confirmación de asistencia almacenada en Supabase.
- Aviso adicional para los novios mediante WhatsApp.
- Descarga de PDF personalizado con enlace a la invitación.
- Panel privado para modificar la información y revisar confirmaciones.

## Desarrollo local

```bash
npm install
npm run dev
```

Copia `.env.example` como `.env.local` y configura las credenciales necesarias.
